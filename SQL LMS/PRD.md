# PRD — AI로 배우는 원데이 SQL (LMS)

**버전**: v1.0 (MVP)  
**작성일**: 2026-07-01  
**상태**: 검토 완료

---

## 1. 제품 개요

### 배경

데이터 분석 업무에서 SQL의 중요도는 높지만, 기존 학습 플랫폼은 문법 암기와 직접 타이핑 중심으로 설계되어 있어 실무 활용과 거리가 있다. 현업에서는 AI가 쿼리를 생성해주므로, 학습자가 집중해야 할 핵심 스킬은 **"어떤 데이터를 어떤 형태로 가져와야 하는지 정의하는 능력"** 이다.

본 LMS는 이 관점을 중심으로 설계되며, SQL 문법 이해 + AI 활용 워크플로우 실습을 한 번에 경험할 수 있는 강의 전용 실습 환경을 제공한다.

### 핵심 컨셉

- RDBMS를 엑셀의 여러 표로 비유하여 설명 → SQL은 표를 이용해 표를 만드는 작업
- 문법을 이해하고 예제로 직접 실습하되, 암기보다 이해에 집중
- AI가 쿼리를 생성하므로 학생이 집중할 것은 **Input(필요한 테이블/컬럼)과 Output(원하는 결과물 표)을 정의하는 능력**
- 심화 문제에서는 외부 AI(ChatGPT, Claude 등)로 쿼리를 생성해와 검증

### 목적

- 강의 수강생에게 SQL 문법 실습 환경 제공
- AI를 활용한 쿼리 생성 → 검증 워크플로우를 직접 체험하게 함
- 실무 데이터 분석가 수준의 케이스 문제 다수 제공

### 성공 지표 (MVP)

- 수강생이 로그인 후 문제를 풀고 정답을 확인할 수 있다
- 강사가 어드민에서 문제를 등록하고 수강생을 관리할 수 있다
- 정답 쿼리가 클라이언트에 노출되지 않는다

## 2. 사용자

| 구분 | 설명 |
|---|---|
| **수강생 (Student)** | 강의 등록 학생. 이메일로 사전 등록된 경우에만 접근 가능 |
| **강사 (Admin)** | 강의 운영자. 문제 관리 및 수강생 접근 권한 관리 |

---

## 3. 범위

### MVP 포함

- 이메일 화이트리스트 기반 로그인
- 학습 대시보드 (문제 목록, 필터)
- Track A: 문법 실습 (SQL 에디터 + 채점)
- Track B: AI 워크플로우 (스키마 탐색 + 입력/출력 정의 + 프롬프트 생성 + 채점)
- 어드민: 문제 등록/수정/삭제
- 어드민: 수강생 이메일 관리

### MVP 제외 (2차)

- 진도율 시각화 대시보드
- Output 디자이너 스키마 클릭 연동 (현재는 자유 입력 그리드)
- 힌트 시스템
- 수강생별 풀이 기록 조회 (강사용)

## 5. 기능 명세

### F1. 인증 및 접근 제어

#### User Stories

> **US-01** 수강생으로서, 이메일과 비밀번호로 로그인하고 싶다. 강의 전용 플랫폼이므로 내 수강 여부가 확인된 후에만 접근할 수 있어야 한다.

> **US-02** 강사로서, 등록되지 않은 사람이 플랫폼에 접근하지 못하도록 이메일 화이트리스트로 접근을 제한하고 싶다.

> **US-03** 수강생으로서, 로그인 상태가 유지되어 매번 다시 로그인할 필요가 없으면 좋겠다.

#### Acceptance Criteria

**US-01**
- [ ] 이메일 + 비밀번호 입력 폼이 존재한다
- [ ] 로그인 성공 시 학습 대시보드(`/learn`)로 이동한다
- [ ] 화이트리스트에 없는 이메일로 로그인 시 "접근 권한이 없습니다. 강사에게 문의하세요." 메시지를 표시하고 진입을 차단한다
- [ ] 비밀번호 오류 시 "이메일 또는 비밀번호를 확인해주세요." 메시지를 표시한다
- [ ] 로그아웃 버튼이 존재하며 클릭 시 로그인 화면으로 이동한다

**US-02**
- [ ] 화이트리스트 검증은 서버(RLS)에서 이루어지며 클라이언트 우회가 불가능하다
- [ ] 화이트리스트 미등록 이메일은 Supabase Auth 계정이 존재하더라도 문제/학습 데이터에 접근할 수 없다

**US-03**
- [ ] 세션이 유지되어 브라우저를 닫았다가 다시 열어도 로그인 상태가 유지된다

### F2. 학습 대시보드

#### User Stories

> **US-04** 수강생으로서, 전체 문제 목록을 한 눈에 보고 Track, 도메인, 난이도로 필터링할 수 있으면 좋겠다.

> **US-05** 수강생으로서, 내가 이미 풀었던 문제와 아직 풀지 않은 문제를 구분해서 볼 수 있으면 좋겠다.

#### Acceptance Criteria

**US-04**
- [ ] 로그인 후 `/learn` 진입 시 전체 문제 목록이 표시된다
- [ ] Track 필터: `문법 실습` / `실전 케이스` 선택 가능
- [ ] 도메인 필터(케이스 트랙): 이커머스, SaaS, 핀테크, 물류, 미디어, HR, 커뮤니티 선택 가능
- [ ] 난이도 필터: Easy / Medium / Hard 선택 가능
- [ ] 필터는 중복 선택 가능하며 즉시 목록에 반영된다
- [ ] 각 문제 카드에는 제목, 난이도, 도메인(케이스 트랙), 챕터(문법 트랙)가 표시된다

**US-05**
- [ ] 풀이 완료 문제에는 시각적 표시(체크 또는 색상 변화)가 된다
- [ ] 정답/오답 여부가 구분되어 표시된다

### F3. Track A — 문법 실습

#### User Stories

> **US-06** 수강생으로서, 문법 개념을 배우고 예제 문제를 직접 SQL로 풀어보고 싶다. 작성한 쿼리를 실행하고 결과가 맞는지 즉시 확인하고 싶다.

> **US-07** 수강생으로서, 오답인 경우 내 결과와 기대 결과를 나란히 비교해서 무엇이 다른지 알고 싶다.

#### Acceptance Criteria

**US-06**
- [ ] 문제 페이지에 문제 설명(마크다운 렌더링), 스키마 설명, SQL 에디터가 표시된다
- [ ] 스키마 설명에는 테이블명, 컬럼명, 데이터 타입, 샘플 데이터가 포함된다
- [ ] SQL 에디터에서 쿼리 작성 후 `실행` 버튼 클릭 시 sql.js로 브라우저에서 즉시 실행된다
- [ ] 실행 결과가 표 형태로 에디터 하단에 표시된다
- [ ] `채점` 버튼 클릭 시 서버(Edge Function)에 쿼리를 전송하여 정답 여부를 반환받는다
- [ ] 정답 시 "정답입니다 ✓" 메시지와 함께 해당 문제가 완료 처리된다
- [ ] SQL 오류 발생 시 오류 메시지를 에디터 하단에 표시한다
- [ ] 쿼리 실행 5초 초과 시 자동 중단 및 타임아웃 안내 메시지 표시

**US-07**
- [ ] 오답 시 내 결과 / 기대 결과를 나란히 표시한다
- [ ] 두 결과의 차이가 있는 행/셀을 강조 표시한다
- [ ] 정답 쿼리 자체는 표시하지 않는다 (결과만 공개)

### F4. Track B — AI 워크플로우

#### User Stories

> **US-08** 수강생으로서, 주어진 비즈니스 문제를 보고 어떤 테이블과 컬럼이 필요한지 파악하고 선택해보고 싶다.

> **US-09** 수강생으로서, 내가 받아야 할 결과물 표를 직접 설계해보고 싶다.

> **US-10** 수강생으로서, 내가 정의한 입력/출력 정보를 바탕으로 외부 AI에 요청할 수 있는 프롬프트를 자동으로 생성해주면 좋겠다.

> **US-11** 수강생으로서, AI가 생성한 쿼리를 플랫폼에 붙여넣고 실행해서 내가 설계한 결과물과 일치하는지 확인하고 싶다.

> **US-12** 수강생으로서, AI 워크플로우 대신 직접 쿼리를 작성하고 싶을 때 에디터로 전환할 수 있으면 좋겠다.

#### Acceptance Criteria

**US-08 — 스키마 탐색 & 입력 선택**
- [ ] 문제 페이지 좌측에 스키마 탐색기 패널이 표시된다
- [ ] 스키마 탐색기에는 테이블 목록과 각 컬럼(이름, 타입, 설명)이 펼쳐 볼 수 있는 형태로 표시된다
- [ ] 각 컬럼 옆 체크박스로 "이 문제에 필요한 컬럼"을 선택할 수 있다
- [ ] 선택한 컬럼 목록이 STEP 1 영역에 실시간으로 반영된다
- [ ] 채점 시 선택한 컬럼 목록과 정답 컬럼 목록을 비교하여 피드백 제공 (감점 없이 참고용)

**US-09 — 아웃풋 그리드 디자이너**
- [ ] STEP 2 영역에 빈 표 형태의 아웃풋 그리드가 표시된다
- [ ] `+ 컬럼 추가` 버튼으로 컬럼을 추가하고 컬럼명을 직접 입력할 수 있다
- [ ] 컬럼 삭제 버튼(×)이 각 컬럼 헤더에 존재한다
- [ ] 헤더 아래 샘플 행을 직접 입력할 수 있다
- [ ] 정렬 기준 입력란이 있다
- [ ] 예상 행 수 입력란이 있다 (선택 입력)

**US-10 — AI 프롬프트 자동 생성**
- [ ] `AI에게 요청하기` 버튼 클릭 시 아래 내용을 포함한 프롬프트가 생성된다
  - 문제 시나리오 설명
  - 전체 DB 스키마 (테이블명, 컬럼, 타입)
  - 학생이 선택한 입력 테이블/컬럼
  - 학생이 설계한 아웃풋 표 (컬럼명, 샘플 행, 정렬 기준)
  - SQLite 쿼리 작성 요청 문구
- [ ] 프롬프트 전체가 클립보드에 복사되며 "복사되었습니다" 토스트 메시지가 표시된다

**US-11 — 쿼리 붙여넣기 & 검증**
- [ ] STEP 3 영역에 SQL 에디터가 표시된다
- [ ] 쿼리 붙여넣기 후 `실행` 버튼으로 sql.js 즉시 실행 가능하다
- [ ] 실행 결과가 표로 표시된다
- [ ] `채점` 버튼 클릭 시 서버에서 정답 쿼리 결과와 비교하여 정답 여부를 반환한다
- [ ] 정답/오답 피드백은 Track A와 동일하게 제공된다

**US-12 — 직접 작성 모드 전환**
- [ ] 문제 페이지 상단에 `AI 워크플로우` / `직접 작성` 탭이 존재한다
- [ ] `직접 작성` 탭 선택 시 스키마 탐색기 + SQL 에디터 + 실행/채점만 표시된다
- [ ] 두 탭 간 전환 시 작성 중인 쿼리가 유지된다

### F5. 어드민 — 문제 관리

#### User Stories

> **US-13** 강사로서, 새로운 문제를 직접 등록하고 싶다. 문제 설명, 스키마, DDL/DML, 정답 쿼리를 입력하고 관리할 수 있어야 한다.

> **US-14** 강사로서, 등록한 문제를 수정하거나 삭제할 수 있어야 한다.

> **US-15** 강사로서, 문제 등록 전에 정답 쿼리가 올바른 결과를 내는지 미리 테스트하고 싶다.

#### Acceptance Criteria

**US-13**
- [ ] `/admin/problems/new`에서 문제 등록 폼에 접근할 수 있다
- [ ] 등록 폼 필드: 제목, 트랙, 챕터, 도메인, 난이도, 문제 설명(마크다운), 스키마 설명, setup_sql, solution_sql, 채점 모드(ordered/unordered), 정답 입력 컬럼(Track B용), 태그
- [ ] 저장 버튼 클릭 시 DB에 저장되고 목록 페이지로 이동한다

**US-14**
- [ ] 문제 목록에서 수정/삭제 버튼에 접근할 수 있다
- [ ] 삭제 시 확인 다이얼로그가 표시된다
- [ ] 수정 폼은 기존 데이터가 채워진 상태로 열린다

**US-15**
- [ ] 등록/수정 폼에서 `테스트 실행` 버튼 클릭 시 setup_sql + solution_sql 실행 결과를 미리보기로 표시한다
- [ ] 오류 발생 시 오류 메시지가 표시된다

### F6. 어드민 — 수강생 관리

#### User Stories

> **US-16** 강사로서, 새 수강생의 이메일을 화이트리스트에 추가해서 플랫폼 접근을 허용하고 싶다.

> **US-17** 강사로서, 수강이 종료된 학생의 접근을 차단하고 싶다.

#### Acceptance Criteria

**US-16**
- [ ] `/admin/whitelist`에서 현재 등록된 이메일 목록을 볼 수 있다
- [ ] 이메일 + 메모 입력 후 `추가` 버튼으로 화이트리스트에 등록할 수 있다
- [ ] 이미 등록된 이메일 입력 시 "이미 등록된 이메일입니다" 메시지를 표시한다
- [ ] 목록에 등록일, 메모(이름 등) 컬럼이 표시된다

**US-17**
- [ ] 각 이메일 행에 삭제 버튼이 있으며 클릭 시 화이트리스트에서 제거된다
- [ ] 제거 즉시 해당 이메일 세션은 다음 요청부터 접근이 차단된다

## 6. 비기능 요구사항

| 항목 | 요구사항 |
|---|---|
| **보안** | `solution_sql`은 클라이언트에 절대 전송되지 않으며 Edge Function에서만 참조 |
| **보안** | 화이트리스트 검증은 Supabase RLS로 서버에서 강제 |
| **보안** | 어드민 기능은 `is_admin = true` 유저만 접근 가능 (RLS + 라우트 가드) |
| **성능** | SQL 실행 타임아웃 5초 |
| **성능** | 문제 목록 초기 로딩 2초 이내 |
| **가용성** | 수강생 50명 이하 기준 무료 티어 내 운영 |
| **호환성** | Chrome, Safari, Edge 최신 버전 지원 |

## 7. 미결 사항

| 항목 | 내용 |
|---|---|
| 비밀번호 초기화 | 수강생이 비밀번호를 잊었을 때의 처리 방법 (이메일 초기화 vs 강사 직접 처리) |

| 문제 공개 범위 | 특정 문제를 특정 기수에게만 공개하는 기능 필요 여부 |
