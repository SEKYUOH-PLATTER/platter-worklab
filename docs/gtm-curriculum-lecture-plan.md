# GTM 실전 커리큘럼 강의안

## 과정 개요

| 항목 | 내용 |
|------|------|
| **과정명** | IT 비즈니스 GTM(Go-To-Market) 전략 실전 과정 |
| **총 시간** | 15시간 (5일 x 3시간) |
| **대상** | IT 업계 마케터/기획자 지망 취업준비생 |
| **수준** | 입문 (사전 지식 불요) |
| **형태** | 오프라인 대면 강의 |
| **AI 도구** | Google Gemini (무료 버전) |

## 과정 목표

본 과정을 수료한 수강생은 다음을 할 수 있다:

1. IT 프로덕트의 라이프사이클과 GTM 전략의 역할을 설명할 수 있다
2. 데이터 기반으로 타겟 고객을 정의하고 페인포인트를 도출할 수 있다
3. 가치 제안(VP)과 포지셔닝을 수립하고, 메시징 프레임워크를 작성할 수 있다
4. 채널 전략을 설계하고 성과 지표(KPI)를 설정할 수 있다
5. Gemini를 활용하여 GTM 리서치와 분석 업무를 효율화할 수 있다
6. 위 역량을 이력서/면접에서 어필하는 방법을 알고 적용할 수 있다

## 과정 구조 한눈에 보기

```
Day 1: 뼈대 잡기    ─── GTM이 뭔지, 왜 필요한지 이해
Day 2: 고객 찾기    ─── 누구에게 팔 건지 정의
Day 3: 메시지 만들기 ─── 뭐라고 말할 건지 기획
Day 4: 채널 & 지표  ─── 어디서 어떻게, 성과는 어떻게 측정할지
Day 5: 실전 연결    ─── 런칭 이후 운영 + 취업 무기화
```

# Day 1: IT 비즈니스의 뼈대와 GTM의 논리 이해 (3H)

## Day 1 학습 목표

- IT 프로덕트가 아이디어에서 시장 출시까지 거치는 과정을 설명할 수 있다
- GTM 전략의 정의와 구성 요소를 나열할 수 있다
- 성공/실패 GTM 사례를 통해 '가설 검증' 중심 사고의 필요성을 이해한다
- Gemini를 활용한 시장 리서치 프롬프트를 직접 작성할 수 있다

---

### 1교시: 아이디어가 프로덕트가 되기까지의 라이프사이클과 GTM의 역할 (50분)

#### 도입 (10분)

**아이스브레이킹 & 동기 부여**

- 질문 던지기: "여러분이 좋아하는 앱 하나를 떠올려 보세요. 그 앱이 세상에 나오기까지 어떤 과정이 있었을까요?"
- 수강생 2-3명 간단 발표 (자유롭게)
- 강사 코멘트: 우리가 일상에서 쓰는 서비스도 '아이디어 → 검증 → 개발 → 출시 → 성장'의 과정을 거친다는 것을 환기

**과정 오리엔테이션**

- 5일간의 커리큘럼 로드맵 간략 소개
- "이 과정이 끝나면 여러분은 GTM 전략을 직접 설계하고, 이를 면접에서 어필할 수 있는 사람이 됩니다"

#### 전개 (30분)

**프로덕트 라이프사이클의 이해**

핵심 개념:
- 프로덕트 라이프사이클 4단계: 도입기 → 성장기 → 성숙기 → 쇠퇴기
- 각 단계별 핵심 과업과 의사결정 포인트

시각 자료:
- 프로덕트 라이프사이클 곡선 그래프
- 각 단계별 실제 서비스 사례 매핑 (예: 쿠팡이츠 도입기, 배달의민족 성숙기)

**GTM 전략이란 무엇인가**

핵심 개념:
- GTM의 정의: "만든 제품을 어떻게 시장에 내놓고, 고객에게 전달할 것인가에 대한 종합 전략"
- GTM ≠ 마케팅. GTM은 마케팅을 포함하는 상위 개념
- GTM의 5대 구성 요소:
  1. 타겟 고객 정의 (Who)
  2. 가치 제안 (What)
  3. 채널 전략 (Where)
  4. 메시징 (How to communicate)
  5. 성과 지표 (How to measure)

시각 자료:
- GTM 구성 요소 다이어그램 (5개 요소가 서로 연결된 구조)
- "마케팅 vs GTM" 비교표

**프로덕트 팀 내 GTM 관련 역할**

핵심 개념:
- PM/PO, 마케터, 그로스 담당, 데이터 분석가 등의 역할 구분
- 기획자와 마케터가 GTM에서 담당하는 영역
- "취준생이 왜 GTM을 알아야 하는가": 기획자/마케터에게 GTM 역량이 곧 핵심 경쟁력인 이유

#### 정리 (10분)

- 핵심 개념 요약: 프로덕트 라이프사이클 → GTM의 정의와 구성 요소
- Quick Quiz: "GTM 전략의 5대 구성 요소를 말해보세요" (수강생 참여)
- 다음 교시 예고: "그러면 GTM을 '잘' 하려면 어떻게 해야 할까요?"

### 2교시: 실패하는 GTM vs 성공하는 GTM (50분)

#### 도입 (5분)

- 질문: "좋은 제품인데 망한 경우를 본 적 있나요? 왜 망했을까요?"
- 핵심 메시지: "좋은 제품 ≠ 성공. GTM이 잘못되면 아무리 좋은 제품도 실패한다"

#### 전개 (35분)

**실패하는 GTM의 공통 패턴**

사례 1: 직관에 의존한 GTM
- "우리 제품은 모든 사람에게 필요해" → 타겟 불명확
- "이 기능이 좋으니까 당연히 잘 될 거야" → 고객 관점 부재
- 국내 스타트업 실패 사례 1-2개 간략 소개

사례 2: 타이밍과 채널 미스매치
- 제품은 B2B인데 인스타그램 광고에 올인한 경우
- 시장이 아직 준비되지 않은 상태에서 런칭한 경우

**성공하는 GTM의 핵심 원리: 가설 검증 사이클**

핵심 프레임워크:
```
가설 수립 → 데이터 수집 → 분석 → 검증/반증 → 개선 → 반복
```

- 가설 수립의 예시: "우리 타겟은 20대 직장인이고, 이들의 핵심 페인포인트는 ○○이다"
- 가설은 '맞다/틀리다'로 판별 가능해야 한다 (측정 가능한 형태)
- 직관 vs 가설의 차이: "느낌이 좋다" vs "이 지표가 N% 이상이면 유효하다"

**데이터 리터러시의 기초**

핵심 개념:
- 데이터 리터러시란: 데이터를 읽고, 해석하고, 의사결정에 활용하는 능력
- 취준생/주니어에게 필요한 데이터 리터러시 수준
  - 코딩이나 통계 전문 지식이 아님
  - "이 숫자가 의미하는 바를 해석하고, 다음 액션을 제안하는 것"
- 기본 지표 읽기:
  - DAU/MAU, 전환율(CVR), 이탈률, 리텐션
  - 각 지표의 의미와 "그래서 뭘 해야 하는데?"로 연결하는 사고방식

시각 자료:
- 직관 기반 의사결정 vs 데이터 기반 의사결정 비교 인포그래픽
- 가설 검증 사이클 순환 다이어그램

#### 정리 (10분)

- 핵심 메시지 요약: "GTM의 성패는 '감'이 아니라 '가설 → 검증'의 반복에 달려 있다"
- 생각해볼 질문: "내가 좋아하는 서비스의 GTM 전략은 어떤 가설에서 출발했을까?"
- 다음 교시 예고: "이제 직접 해볼 차례입니다. AI를 활용해서 시장을 리서치해봅시다"

### 3교시 [라이브 데모]: Gemini를 활용한 시장 트렌드 및 경쟁사 리서치 효율화 (50분)

#### 도입 (5분)

- "지금부터는 직접 따라하면서 배우는 시간입니다"
- Gemini 접속 안내 (gemini.google.com, Google 계정 로그인)
- AI를 활용한 리서치의 장점과 한계 간략 설명
  - 장점: 빠른 초기 리서치, 아이디어 확장, 구조화
  - 한계: 환각(Hallucination), 최신 정보 정확도, 반드시 교차 검증 필요

#### 전개 (35분)

**Step 1: 논리적 프롬프트 구조화의 원칙 (10분)**

프롬프트 작성의 3원칙:
1. **역할(Role) 부여**: "너는 IT 서비스 시장 분석 전문가야"
2. **맥락(Context) 제공**: 구체적인 상황, 산업, 범위 명시
3. **출력 형식(Format) 지정**: 표, 리스트, 단계별 등 원하는 형태 명시

나쁜 프롬프트 vs 좋은 프롬프트 비교:
- 나쁜 예: "배달 앱 시장에 대해 알려줘"
- 좋은 예: "너는 한국 O2O 서비스 시장 분석가야. 2024-2025년 한국 음식 배달 앱 시장의 주요 트렌드 5가지를 표 형식으로 정리해줘. 각 트렌드별로 ①트렌드명 ②설명 ③대표 서비스 ④취준생이 알아야 할 시사점을 포함해줘."

**Step 2: 시장 트렌드 리서치 시연 (10분)**

라이브 데모 시나리오: "중고거래 플랫폼 시장"을 예시로 사용

프롬프트 시연 1 - 시장 개요 파악:
```
[Gemini 프롬프트 예시]
너는 한국 C2C 커머스 시장 분석 전문가야.

한국 중고거래 플랫폼 시장의 현재 상황을 다음 구조로 분석해줘:
1. 시장 규모 및 성장 추이 (최근 3년)
2. 주요 플레이어와 각각의 포지셔닝
3. 최근 1년간 주목할 만한 시장 변화 3가지
4. 이 시장에 신규 진입하려는 서비스가 고려해야 할 핵심 요소

각 항목은 구체적인 수치나 사례를 포함해서 답변해줘.
```

결과를 함께 읽으며:
- "이 정보가 정확한지 어떻게 검증할 수 있을까?" (교차 검증의 중요성)
- "어떤 부분을 더 깊이 파야 할까?" (후속 질문 유도)

**Step 3: 경쟁사 분석 시연 (10분)**

프롬프트 시연 2 - 경쟁사 비교 분석:
```
[Gemini 프롬프트 예시]
한국 중고거래 시장의 주요 서비스 3개(당근마켓, 번개장터, 중고나라)를
다음 기준으로 비교 분석해줘:

| 비교 항목 | 당근마켓 | 번개장터 | 중고나라 |
|-----------|----------|----------|----------|
| 핵심 타겟 고객 | | | |
| 주요 가치 제안 | | | |
| 수익 모델 | | | |
| 차별화 포인트 | | | |
| 최근 주요 전략 변화 | | | |

이후 이 시장에서 아직 해결되지 않은 고객 불만(Unmet Needs)

결과를 함께 읽으며:

**Step 4: 수강생 실습 (5분)**

- 본인이 관심 있는 IT 서비스 분야를 하나 정해서 Gemini로 시장 트렌드 프롬프트를 직접 작성해보기
- 강사가 돌아다니며 피드백

#### 정리 (10분)

- 오늘 배운 것 요약:
  1. 프로덕트 라이프사이클과 GTM의 역할

# Day 2: 타겟 고객 정의와 페인포인트 발굴 (3H)

## Day 2 학습 목표

- 고객 세분화(Segmentation)의 기준과 방법론을 이해하고 적용할 수 있다
- 뾰족한 페르소나를 설정하는 논리 구조를 설명할 수 있다
- 리뷰/커뮤니티 등 실제 데이터에서 페인포인트를 추출하는 방법을 실습한다
- Gemini를 활용하여 특정 서비스의 페르소나와 페인포인트를 역추적할 수 있다

---

### 1교시: 전략적 고객 세분화 및 뾰족한 페르소나 설정 로직 (50분)

#### 도입 (10분)

**Day 1 복습 & 연결**

- Quick Recap: "어제 우리가 배운 GTM의 5대 요소 중 첫 번째는?" → 타겟 고객 정의
- 과제 공유: 1-2명 자발적으로 시장 리서치 결과 간략 공유 (2-3분)
- 오늘의 핵심 질문: "모든 사람이 고객이면, 아무도 고객이 아니다. 그러면 어떻게 '진짜 고객'을 찾을까?"

#### 전개 (30분)

**고객 세분화(Segmentation)란**

핵심 개념:
- 세분화의 정의: 전체 시장을 의미 있는 하위 그룹으로 나누는 것
- 세분화의 4가지 기준:
  1. **인구통계적(Demographic)**: 나이, 성별, 소득, 직업
  2. **지리적(Geographic)**: 지역, 도시 규모
  3. **심리적(Psychographic)**: 가치관, 라이프스타일, 관심사
  4. **행동적(Behavioral)**: 사용 빈도, 구매 패턴, 브랜드 충성도

핵심 강조:
- "입문자들이 흔히 인구통계적 세분화에만 집중하는데, 실제 GTM에서 가장 중요한 것은 **행동적 세분화**입니다"
- 행동 기반 세분화가 중요한 이유: 같은 20대여도 '중고거래를 주 3회 하는 파워셀러'와 '한 달에 한 번 구경만 하는 사람'은 완전히 다른 고객

사례:
- 토스의 세분화: "20대" (인구통계)가 아니라 "금융 서비스에 불편을 느끼는 디지털 네이티브" (행동+심리)
- 당근마켓의 세분화: "서울 거주자"가 아니라 "동네 기반의 신뢰할 수 있는 거래를 원하는 사람" (행동+심리)

**뾰족한 페르소나 설정**

핵심 개념:
- 페르소나 ≠ 타겟 오디언스. 페르소나는 타겟의 "대표 인물"을 구체적으로 그린 것
- 뾰족한 페르소나의 조건:
  1. 이름, 나이, 직업 등 기본 정보 (구체적으로)
  2. **핵심 목표(Goal)**: 이 사람이 달성하고 싶은 것
  3. **핵심 불만(Pain Point)**: 목표 달성을 방해하는 것
  4. **현재 해결 방식**: 지금은 이 문제를 어떻게 해결하고 있는가
  5. **정보 접근 채널**: 어디서 정보를 얻는가 (SNS, 커뮤니티, 지인 등)

페르소나 설정 실습 프레임워크:
```
이름: 김지현 (28세, 스타트업 마케터 2년차)
핵심 목표: 한정된 예산으로 효과적인 마케팅 캠페인 성과를 내고 싶다
핵심 불만: 데이터 분석 역량이 부족해서 감으로 의사결정하게 된다
현재 해결 방식: 블로그 글, 유튜브 영상으로 독학
정보 접근 채널: 인스타그램, 마케팅 관련 오픈채팅방, 브런치
```

주의사항:
- "내가 상상하는 고객"이 아니라 "실제 데이터에서 도출된 고객"이어야 한다
- → 이것이 2교시의 주제로 연결

#### 정리 (10분)

- 핵심 정리: 세분화 4가지 기준 → 행동 기반이 핵심 → 뾰족한 페르소나 5요소
- 전환 질문: "그런데 이 페르소나를 '상상'이 아니라 '데이터'로 만들려면 어디서 데이터를 구해야 할까요?"

### 2교시: 시장 내 흩어진 데이터로 진짜 고객의 Pain Point 도출하기 (50분)

#### 도입 (5분)

- "고객의 진짜 목소리는 어디에 있을까요?"
- 답: 앱스토어 리뷰, 커뮤니티(에브리타임, 블라인드, 디시인사이드), SNS, 고객 CS 문의 등
- "이런 데이터는 구조화되어 있지 않고 흩어져 있어요. 이걸 어떻게 체계적으로 정리할까요?"

#### 전개 (35분)

**비정형 데이터에서 인사이트를 추출하는 방법**

핵심 개념:
- 비정형 데이터의 종류: 앱 리뷰, 커뮤니티 글, SNS 댓글, CS 문의
- 데이터 수집 → 분류 → 패턴 발견 → 인사이트 도출의 프로세스

실습용 프레임워크 - Pain Point 분류 매트릭스:
```
| 카테고리 | 구체적 불만 | 빈도 | 심각도 | 현재 대안 |
|----------|------------|------|--------|----------|
| 기능적   |            | 높/중/낮 | 높/중/낮 |      |
| 감정적   |            |      |        |          |
| 사회적   |            |      |        |          |
```

- **기능적 Pain Point**: "앱이 느려요", "결제가 안 돼요" (직접적 불편)
- **감정적 Pain Point**: "불안해요", "신뢰가 안 가요" (심리적 장벽)
- **사회적 Pain Point**: "주변에 아는 사람이 없어요", "혼자만 쓰는 느낌" (관계/소속)

**실전 사례: 앱 리뷰에서 Pain Point 추출하기**

라이브 시연:
1. Google Play 또는 App Store에서 특정 앱(예: 당근마켓)의 별점 1-3점 리뷰 10개를 화면에 띄우기
2. 함께 읽으며 Pain Point 분류 매트릭스에 정리
3. 패턴 발견: "가장 많이 언급되는 불만은 무엇인가?"
4. 인사이트 도출: "이 패턴이 의미하는 바는?"

강사 팁:
- 별점 1-2점만 보면 극단적 의견에 치우침 → 별점 3점 리뷰가 가장 건설적인 피드백이 많음
- 리뷰의 "글자 수"도 힌트: 길게 쓴 리뷰일수록 강한 감정이 담겨 있음

**커뮤니티 데이터 활용법**

핵심 개념:
- 에브리타임, 블라인드, 디시인사이드, 네이버 카페 등에서 키워드 검색
- 검색 키워드 예시: "[서비스명] 불편", "[서비스명] 대안", "[서비스명] 탈퇴"
- 커뮤니티별 특성:
  - 에브리타임: 20대 대학생의 솔직한 의견
  - 블라인드: 직장인의 실무 관점 피드백
  - 맘카페: 30-40대 부모의 실사용 리뷰

#### 정리 (10분)

- 핵심 요약: 비정형 데이터 → Pain Point 분류 매트릭스 → 패턴 → 인사이트
- 전환: "이 과정을 AI로 훨씬 빠르게 할 수 있습니다. 다음 시간에 직접 해봅시다"

```
[Gemini 프롬프트 예시]
앞에서 분석한 당근마켓의 초기 타겟 고객을 기반으로,
구체적인 사용자 페르소나 2개를 만들어줘.

각 페르소나는 다음 항목을 포함해야 해:
- 이름, 나이, 직업, 거주 지역

이 리뷰들을 분석해서 다음을 도출해줘:

3. 가장 심각한 Pain Point와 그 이유
4. 이 Pain Point를 해결하기 위한 개선 방향 2가지 제안

표 형식으로 정리해줘.
```

강사 코멘트:

### 1교시: 핵심 가치 제안(Value Proposition) 도출과 포지셔닝 (50분)

#### 도입 (10분)

**Day 2 복습 & 연결**

- Quick Recap: 지난 시간 도출한 페르소나와 Pain Point를 환기
- 오늘의 핵심 질문: "고객의 Pain Point를 알았다. 그래서 우리 서비스가 그 문제를 어떻게 풀어줄 것인가?"
- "이것이 바로 가치 제안(Value Proposition)입니다"

#### 전개 (30분)

**가치 제안(Value Proposition)의 이해**

핵심 개념:
- 가치 제안 = "고객이 우리 서비스를 선택해야 하는 단 하나의 이유"
- 흔한 실수: "우리 서비스는 빠르고, 편리하고, 저렴합니다" → 아무것도 말하지 않은 것과 같다
- 좋은 가치 제안의 조건:
  1. 구체적 (모호하지 않음)
  2. 차별적 (경쟁사와 다름)
  3. 고객 관점 (기업이 자랑하는 것이 아님)

Value Proposition Canvas (간소화 버전):

```
┌─────────────────────────┐     ┌─────────────────────────┐
│      고객 프로필          │     │      가치 맵             │
│                         │     │                         │
│  해결하고 싶은 일(Jobs)   │◄───►│  제품/서비스             │
│  Pain Point             │◄───►│  Pain Reliever          │
│  기대하는 이득(Gains)     │◄───►│  Gain Creator           │
└─────────────────────────┘     └─────────────────────────┘
```

- 왼쪽(고객 프로필)은 Day 2에서 이미 도출
- 오른쪽(가치 맵)을 채우는 것이 오늘의 과업

사례:
- 토스의 가치 제안: "금융이 어려운 보통 사람들에게 → 쉽고 간편한 금융 경험을" (Pain: 복잡한 금융 → Reliever: 원탭 송금)
- 당근마켓의 가치 제안: "동네 주민에게 → 믿을 수 있는 중고거래를" (Pain: 사기 불안 → Reliever: 동네 인증)

**포지셔닝**

핵심 개념:
- 포지셔닝 = "고객의 머릿속에 우리 서비스가 차지하는 위치"
- 포지셔닝 ≠ 우리가 정하는 것. 고객이 인식하는 것. 단, 우리가 유도할 수 있음
- 포지셔닝 스테이트먼트 공식:

```
[타겟 고객]에게
[서비스명]은
[경쟁 카테고리] 중에서
[핵심 차별점]을 제공하는 서비스이다.
왜냐하면 [근거/증거]이기 때문이다.
```

- 예시 (배달의민족):
  - 바쁜 직장인에게 / 배달의민족은 / 음식 주문 서비스 중에서 / 가장 다양한 선택지와 재미있는 경험을 제공하는 서비스이다 / 왜냐하면 업계 최다 입점 식당과 B급 감성 브랜딩을 갖추고 있기 때문이다

**포지셔닝 맵 그리기**

- X축, Y축에 고객이 중시하는 2가지 기준을 설정
- 경쟁 서비스들의 위치를 표시
- "비어 있는 공간"이 곧 기회

시각 자료:
- 중고거래 플랫폼 포지셔닝 맵 예시 (X: 거래 편의성, Y: 신뢰도)

#### 정리 (10분)

- VP Canvas → 포지셔닝 스테이트먼트 → 포지셔닝 맵의 흐름 정리
- "가치 제안과 포지셔닝이 정해졌으면, 이제 '어떤 말로 전달할 것인가'가 남았습니다"

### 2교시: 고객의 마음을 움직이는 메시징 프레임워크와 카피라이팅 논리 (50분)

#### 도입 (5분)

- "같은 제품도 어떻게 말하느냐에 따라 전혀 다른 반응을 얻습니다"
- 사례 비교:
  - A: "우리 앱은 AI 기반 추천 알고리즘을 탑재했습니다" (기능 중심)
  - B: "매일 아침, 당신의 취향에 딱 맞는 옷을 골라드립니다" (고객 가치 중심)
  - "어떤 문장에 더 마음이 끌리나요?"

#### 전개 (35분)

**메시징 프레임워크의 구조**

핵심 개념:
- 메시지 계층 구조:
  1. **브랜드 메시지** (최상위): 서비스의 핵심 정체성 한 문장
  2. **가치 메시지** (중위): 타겟별 핵심 가치 전달
  3. **증거 메시지** (하위): 가치를 뒷받침하는 구체적 사실/수치

예시 (토스):
```
브랜드 메시지: "금융을 쉽게"
├── 가치 메시지 (20대): "첫 월급부터 똑똑한 자산관리"
│   └── 증거: "가입 3분 만에 내 소비 패턴 분석 완료"
├── 가치 메시지 (30대 부모): "아이 용돈도 간편하게"
│   └── 증거: "토스 용돈 기능 월 이용자 100만 명"
└── 가치 메시지 (소상공인): "매출 정산을 한눈에"
    └── 증거: "토스 비즈니스 가입 소상공인 50만"
```

핵심 포인트:
- 같은 서비스라도 타겟에 따라 강조하는 가치가 다르다
- 메시징 프레임워크가 있어야 일관되면서도 타겟 맞춤형 커뮤니케이션이 가능

**카피라이팅의 기본 논리**

핵심 원칙:
1. **기능이 아닌 혜택을 말하라**
   - X: "256GB 저장 공간" → O: "사진 10만 장을 걱정 없이 저장하세요"
2. **고객의 언어를 써라**
   - X: "옴니채널 통합 CRM 솔루션" → O: "고객 문의, 한 곳에서 다 관리하세요"
3. **구체적인 숫자를 활용하라**
   - X: "빠른 배달" → O: "주문 후 평균 28분 도착"
4. **행동을 유도하라 (CTA)**
   - "지금 시작하기", "무료로 체험하기", "3초 만에 가입"

실습:
- 강사가 예시 기능 3개 제시 → 수강생이 혜택 중심 카피로 바꿔보기
- 예: "AI 기반 맞춤 추천" → "나만을 위한 ○○을 3초 만에 발견하세요"

- "이론을 배웠으니, AI를 활용해서 실전 메시지를 만들어봅시다"

### 1교시: 초기 리소스 한계를 극복하는 채널 믹스 전략 (50분)

**Day 3 복습 & 연결**

- Quick Recap: VP, 포지셔닝, 메시징 — "무엇을 말할지는 정했다. 이제 어디서 말할지를 정할 차례"

#### 전개 (30분)

**미디어의 3가지 유형: Owned / Earned / Paid**

| 유형 | 정의 | 예시 | 장점 | 단점 |
|------|------|------|------|------|
| **Owned** | 우리가 소유한 채널 | 자사 블로그, 앱, 뉴스레터, SNS 계정 | 통제 가능, 비용 낮음 | 도달 범위 한정적, 시간 소요 |
| **Earned** | 제3자가 자발적으로 만든 노출 | 언론 보도, 사용자 리뷰, 입소문, 바이럴 | 신뢰도 높음, 비용 없음 | 통제 불가, 예측 어려움 |
| **Paid** | 비용을 지불한 광고 | 검색 광고, SNS 광고, 인플루언서 협업 | 즉각적 도달, 타겟팅 가능 | 비용 높음, 중단 시 효과 소멸 |

핵심 포인트:
- 세 유형은 독립적이 아니라 상호 보완적
- 초기 스타트업의 현실: Paid에 쓸 예산이 없다 → Owned와 Earned 중심으로 시작

**초기 스타트업의 채널 전략 원칙**

원칙 1: "한 채널에서 먼저 이기고, 그다음 확장하라"
- 모든 채널에 분산하면 어디서도 임팩트를 내지 못함
- 타겟 고객이 가장 많이 모여 있는 '핵심 채널' 1-2개에 집중

원칙 2: "채널 선택의 기준은 '우리가 잘하는 것'이 아니라 '고객이 있는 곳'"
- 페르소나의 "정보 접근 채널"(Day 2)이 채널 선택의 출발점
- 예: 타겟이 20대 대학생 → 에브리타임, 인스타그램
- 예: 타겟이 30대 직장인 → 블라인드, 링크드인, 뉴스레터

원칙 3: "초기에는 '스케일'보다 '학습'이 목적"
- 초기 채널 운영의 목적은 대량 트래픽이 아니라 "우리 메시지가 타겟에게 통하는가?" 검증
- 작은 규모로 빠르게 테스트 → 데이터 확인 → 확대/전환 판단

|------|------|-----------|------|---------|---------|
|      | O/E/P | 상/중/하  | 상/중/하 | 1/2/3 |         |
```

### 2교시: GTM 성공을 판단하는 성과 측정 지표 설정 (50분)

#### 도입 (5분)

- "마케팅을 했는데 효과가 있었는지 모르겠다" → 이것이 KPI 부재의 결과
- "지표 없는 GTM은 목적지 없는 네비게이션과 같다"

#### 전개 (35분)

**North Star Metric (핵심 지표)**

핵심 개념:
- North Star Metric = 서비스의 성공을 가장 잘 대변하는 단 하나의 지표
- 좋은 NSM의 조건:
  1. 고객 가치를 반영한다
  2. 매출/성장과 연결된다
  3. 팀 전체가 이해하고 움직일 수 있다

사례:
| 서비스 | North Star Metric | 이유 |
|--------|-------------------|------|
| 당근마켓 | 월간 거래 완료 건수 | 거래 성사 = 핵심 가치 전달의 증거 |
| 토스 | 월간 활성 사용자(MAU) | 다양한 금융 서비스의 통합 사용 = 핵심 가치 |
| 배달의민족 | 월간 주문 건수 | 주문 = 매출과 고객 만족의 교차점 |
| 뤼튼 | 일간 대화 생성 수 | AI 대화 활용 = 서비스 핵심 가치의 직접 지표 |

**단계별 KPI 설계: AARRR 프레임워크**

```
Acquisition (획득) → Activation (활성화) → Retention (유지) 
→ Revenue (수익) → Referral (추천)
```

각 단계별 핵심 지표:
| 단계 | 의미 | 핵심 지표 예시 |
|------|------|---------------|
| Acquisition | 고객이 서비스를 알게 됨 | 웹사이트 방문 수, 앱 다운로드 수, 광고 클릭률 |
| Activation | 첫 핵심 가치를 경험 | 회원가입 완료율, 온보딩 완료율, 첫 거래 완료율 |
| Retention | 서비스를 재사용 | DAU/MAU 비율, 7일 리텐션율, 재방문율 |
| Revenue | 수익 발생 | ARPU, 결제 전환율, LTV |
| Referral | 다른 사람에게 추천 | 추천 코드 사용률, NPS, 바이럴 계수 |

핵심 강조:
- GTM 초기에는 모든 단계를 동시에 추적할 필요 없음
- **초기 집중 단계: Acquisition → Activation**
  - "일단 사람들이 오게 만들고 (Acquisition), 와서 '아, 이거 좋네' 느끼게 만드는 것 (Activation)이 우선"
- Retention은 Activation이 어느 정도 안정된 후에 집중

**KPI 설정 실습**

- 예시 서비스를 함께 다루며 AARRR 각 단계별 KPI 1개씩 설정
- "이 KPI가 얼마가 되면 '성공'이라고 할 수 있나?" → 벤치마크 설정의 중요성
  - 업계 평균, 경쟁사 공개 데이터, 자체 과거 데이터 활용

#### 정리 (10분)

- NSM → AARRR → 초기 집중 단계(Acquisition + Activation) 요약
- 다음 교시 예고: "이론은 충분합니다. 실제 스타트업이 어떻게 했는지 분석해봅시다"

### 3교시 [미니 케이스 스터디]: 스타트업 초기 GTM 채널 전략과 KPI 리버스 엔지니어링 (50분)

  1. 채널은 Owned/Earned/Paid를 이해하고, 초기에는 핵심 1-2개에 집중

  3. 실제 성공 사례는 모두 '집중과 검증'의 원칙을 따름
- Day 4 과제:
  - "본인 서비스의 ①채널 믹스 전략표 ②North Star Metric ③AARRR 단계별 KPI를 작성하세요."
- Day 5 예고: "마지막 날은 '런칭 이후'와 '취업 연결'입니다. 지금까지 배운 것을 무기로 만드는 시간입니다."

# Day 5: 런칭 이후의 운영 팁과 '취업 무기'로 만드는 법 (3H)

## Day 5 학습 목표

### 1교시: GTM 런칭은 끝이 아닌 시작 — 전략적 데이터 트래킹 (50분)

#### 도입 (10분)

**전체 과정 흐름 복습**

- 5일간의 여정 요약:
  ```
  Day 1: GTM이 뭔지 알았다
  Day 2: 누구에게 팔지 정했다
  Day 3: 뭐라고 말할지 기획했다
  Day 4: 어디서, 어떻게 측정할지 설계했다
  Day 5: 런칭 이후 어떻게 운영하고, 이걸 취업에 어떻게 쓸 것인가
  ```
- "GTM 전략을 세워서 런칭했다고 끝이 아닙니다. 런칭은 시작입니다."

#### 전개 (30분)

**런칭 직후 확인해야 할 데이터**

런칭 후 첫 1-2주 체크리스트:

| 시점 | 확인 항목 | 핵심 질문 |
|------|----------|----------|
| D+1 | 유입 경로별 트래픽 | "어디서 사람들이 들어오고 있나?" |
| D+1 | 이탈 지점 | "어디서 사람들이 떠나고 있나?" |
| D+3 | 핵심 액션 전환율 | "몇 %가 우리가 원하는 행동을 하고 있나?" |
| D+7 | 리텐션 | "다시 돌아오는 사람이 얼마나 되나?" |
| D+14 | 채널별 효율 | "어떤 채널이 가장 효율적인가?" |

**데이터를 보고 다음 액션을 도출하는 사고방식**

핵심 프레임워크: "So What? → Now What?"

```
데이터 확인 → "So What?" (이 데이터가 의미하는 바는?)
           → "Now What?" (그래서 우리가 해야 할 액션은?)
```

사례 시나리오:
```
상황: 랜딩페이지 방문자 1,000명 중 회원가입은 30명 (전환율 3%)

So What?
- 업계 평균 전환율(5-10%)보다 낮다
- 유입은 되지만 가입 전에 이탈하고 있다

Now What? (가능한 액션)
1. 랜딩페이지 카피가 타겟과 미스매치? → A/B 테스트
2. 가입 과정이 복잡? → 가입 단계 축소 검토
3. 가치 제안이 불명확? → 히어로 섹션 메시지 변경
```

- 수강생과 함께 2-3개 시나리오를 "So What? → Now What?"으로 분석하는 연습
- 강사 실무 경험 공유: "저도 런칭 첫 주에 이런 실수를 했었는데..."

**개선 사이클과 우선순위**

- 모든 문제를 한 번에 고칠 수 없다 → 우선순위 설정이 핵심
- ICE 스코어링:
  - **I**mpact (이 개선이 얼마나 큰 영향을 미칠까? 1-10)
  - **C**onfidence (이 개선이 실제로 효과가 있을 확신은? 1-10)
  - **E**ase (이 개선을 실행하기 얼마나 쉬울까? 1-10)
  - ICE 점수 = (I + C + E) / 3 → 높은 순서대로 실행

#### 정리 (10분)

- 런칭 후 데이터 체크 리스트 → So What/Now What 사고방식 → ICE 우선순위
- "이런 사고방식 자체가 취업에서 강력한 무기가 됩니다"

### 2교시: AI와 데이터로 업무 임팩트 극대화하기 — AX 노하우 방출 (50분)

#### 도입 (5분)

- "코딩을 못해도, 데이터 분석 전공이 아니어도 AI를 활용하면 할 수 있는 것들이 있습니다"
- 이번 시간은 강사의 실무 노하우 공유 중심 (AX = AI Transformation의 실무 적용)

#### 전개 (35분)

**AI를 활용한 데이터 트래킹 개념 소개 (15분)**

"코딩 없이 할 수 있는 것들":
1. **Gemini로 데이터 해석하기**
   - 엑셀/스프레드시트의 데이터를 Gemini에 붙여넣고 분석 요청
   - 예: "이 DAU 데이터의 추세를 분석하고, 이상 징후를 찾아줘"

2. **AI로 리포트 초안 작성하기**
   - 주간/월간 마케팅 리포트를 AI에게 구조화 요청
   - 예: "이 데이터를 기반으로 주간 GTM 성과 리포트를 작성해줘. 항목은 ①핵심 지표 변화 ②성과 요인 ③개선 포인트 ④다음 주 액션 아이템"

3. **간단한 자동화 개념**
   - Google Sheets + 확장 프로그램으로 데이터 자동 수집
   - 노코드 도구(Zapier, Make 등)를 활용한 반복 업무 자동화 개념 소개
   - "직접 세팅하는 방법을 가르치는 것이 아니라, '이런 것이 가능하다'는 것을 아는 것 자체가 경쟁력"

**'일하는 방식의 혁신' 관점 (10분)**

핵심 메시지:
- 도구(tool) 사용법을 아는 것 ≠ 일을 잘하는 것
- AI 시대에 중요한 것:
  1. **올바른 질문을 하는 능력**: 무엇을 분석해야 하는지 아는 것
  2. **결과를 해석하는 능력**: AI가 준 답이 맞는지 판단하는 것
  3. **액션으로 연결하는 능력**: 분석 결과를 실제 개선안으로 바꾸는 것
- "AI는 답을 빨리 주지만, 좋은 질문은 사람이 해야 합니다"

강사 실무 사례 공유 (10분):
- 실제로 AI를 활용해 업무 효율을 높인 사례 2-3개
- Before/After 비교 (소요 시간, 결과물 퀄리티)
- "실패한 사례도 있다 — AI에게 잘못된 질문을 했을 때"

#### 정리 (10분)

- AI 활용의 핵심: 도구 사용법 < 질문력 + 해석력 + 실행력
- "지금까지 5일간 여러분이 연습한 것이 바로 이 '질문력'과 '해석력'입니다"
- 자연스러운 전환: "이 역량을 취업에서 어떻게 보여줄 수 있을까요?"

### 3교시: 사수 없는 주니어의 GTM 면접/취업 전략 (50분)

#### 도입 (5분)

- "GTM 실무 경험이 없어도, 면접에서 GTM 역량을 어필할 수 있습니다"
- "핵심은 '경험'이 아니라 '사고방식'을 보여주는 것입니다"

#### 전개 (35분)

**5일간의 학습을 취업에 연결하는 방법 (15분)**

핵심 전략: "가설 수립 → 데이터 분석 → 논리적 도출" 과정 자체가 어필 포인트

이력서/자소서에 녹여내는 법:

BEFORE (흔한 작성법):
```
"마케팅에 관심이 많고, 다양한 마케팅 관련 강의를 수강했습니다.
SNS 마케팅과 콘텐츠 기획에 관심이 있습니다."
```

AFTER (GTM 역량 기반 작성법):
```
"[서비스명]의 GTM 전략을 분석하며, 타겟 고객의 행동 데이터를 기반으로
핵심 페인포인트를 도출하고, 이를 해결하는 가치 제안과 메시징 전략을
수립한 경험이 있습니다. 앱스토어 리뷰 100건을 분석하여 3개의 핵심
불만 패턴을 발견했고, 이를 기반으로 A/B 테스트 가설을 설계했습니다."
```

STAR 기법 활용:
- **S**ituation: "[서비스명]의 GTM 전략을 학습 프로젝트로 진행"
- **T**ask: "타겟 고객 정의 및 메시징 전략 수립"
- **A**ction: "앱 리뷰 분석, AI 활용 리서치, VP Canvas 작성, A/B 테스트 설계"
- **R**esult: "타겟별 차별화된 메시지 3세트와 채널 전략 도출"

**"GTM 경험이 없는데 어떻게 어필하나요?" — 관점의 전환 (10분)**

핵심 메시지:
- 면접관이 보고 싶은 것은 "경험의 양"이 아니라 "사고의 깊이"
- 실무 경험 없이도 보여줄 수 있는 것들:
  1. **시장을 보는 눈**: "이 시장의 현재 트렌드는 ○○이고, 기회는 ○○입니다"
  2. **고객을 이해하는 관점**: "이 서비스의 핵심 타겟은 ○○이고, 그들의 주요 불만은 ○○입니다"
  3. **논리적 사고력**: "이 가설을 검증하기 위해 ○○ 데이터를 ○○ 방법으로 분석했습니다"
  4. **실행 의지**: "실제로 리뷰 데이터를 수집하고, AI를 활용해 분석했습니다"

면접 예상 질문과 답변 전략:

Q1: "GTM 전략을 수립해본 경험이 있나요?"
- "실무 경험은 없지만, [서비스명]을 대상으로 GTM 전략을 처음부터 끝까지 설계해본 프로젝트 경험이 있습니다. 타겟 정의부터 메시징, 채널 전략, KPI 설정까지 전 과정을 진행했습니다."

Q2: "데이터를 활용해 의사결정한 경험은?"
- "앱스토어 리뷰 데이터와 커뮤니티 의견을 수집·분석하여 핵심 페인포인트 3가지를 도출한 경험이 있습니다. 이를 기반으로 A/B 테스트 가설을 세우고, 측정 지표와 성공 기준을 정의했습니다."

Q3: "AI를 업무에 활용해본 경험은?"
- "Gemini를 활용해 시장 분석과 경쟁사 리서치를 효율화한 경험이 있습니다. 단, AI 결과를 그대로 사용하는 것이 아니라, 실제 데이터와 교차 검증하여 비판적으로 활용하는 방법을 익혔습니다."

**포트폴리오 구성 팁 (10분)**

5일간의 과제물을 포트폴리오로 재구성하는 방법:

포트폴리오 구성 예시:

4. 채널 전략 & KPI (Day 4 과제 기반)

5. 런칭 후 운영 계획 (Day 5 학습 기반)

## 핵심 프레임워크 요약

1. **GTM 5대 구성 요소**: Who / What / Where / How to communicate / How to measure
2. **가설 검증 사이클**: 가설 수립 → 데이터 수집 → 분석 → 검증 → 개선 → 반복
3. **고객 세분화 4기준**: 인구통계적 / 지리적 / 심리적 / 행동적
4. **페르소나 5요소**: 기본정보 / 핵심목표 / 핵심불만 / 현재해결방식 / 정보접근채널
5. **Pain Point 3유형**: 기능적 / 감정적 / 사회적
6. **Value Proposition Canvas**: 고객 프로필 ↔ 가치 맵
7. **포지셔닝 스테이트먼트**: [타겟]에게 [서비스]는 [카테고리] 중 [차별점]을 제공
